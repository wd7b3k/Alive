# Requirements

## Обязательно

- Рендерить `app/src/assets/brand-logo-full.png` с SHA-256 `6b58071efb328d970d921ea6e03d30e15a148d8c36a92f6e9ec05455a830d832`.
- Не хранить и не использовать заменяющий логотип `brand-logo-classic-om.svg`.
- Вернуть маршрут `/facts` с отдельными вкладками «Факты» и «Мифы» на данных R1 Evidence Registry.
- Вернуть видимые входы в раздел из шапки, главной страницы и профиля.
- Убрать точки из статических пользовательских заголовков активного интерфейса.
- Защитить три инварианта автоматическим тестом.

## Non-goals

- Новая продуктовая механика или медицинский content.
- Изменение schema, RLS, аналитики craving flow или расчётов метрик.
- Возврат runtime к legacy `facts_catalog` / `myths_catalog`.
- Редизайн остальных экранов.
