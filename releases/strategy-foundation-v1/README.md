# Strategy Foundation v1

## Purpose

Documentation-only release unit that replaces the previous narrow behavioural strategy with the final ALIVE product/technical foundation.

## Runtime impact

None.

This release intentionally changes no:

- frontend code;
- Supabase migration/schema;
- deployment;
- Cloudflare config;
- production data;
- AI infrastructure;
- Tribute integration.

## Product decisions fixed here

- canonical formula: `Пауза → Реальность → Зачем → Выбор → Опыт → Обучение → Свобода`;
- micro-awareness as contextual layer, not a long wizard;
- Facts/Myths/Goals become active decision components;
- Links include prepared responses;
- Intervention Engine supersedes Replacement Engine as full decision mechanism;
- cigarette/vape/hookah have different behavioural models;
- conscious-use expectation→outcome observation;
- Recovery does not reset history;
- Time Saved / Money Saved / Health Minutes are permanent visible value metrics;
- Health Minutes remain versioned heuristic, not product equivalence;
- referral/self-marketing occurs only after value realization;
- future Tribute donations support development without entitlement/paywall;
- local open-weight LLM comes only after product evidence gate and remains optional to core operation.

## Superseded assumptions

The following old assumptions must no longer drive implementation:

- all cravings must resolve through explicit `need → 3 replacements`;
- `Смыслы` are a passive standalone entity;
- Facts/Myths are secondary library-only content;
- one generic nicotine flow can represent cigarette/vape/hookah;
- ALIVE units can imply health equivalence;
- AI/LLM is a near-term product foundation;
- Together/Admin version labels determine roadmap independently of product evidence.
