# Глоссарий ALIVE

## ALIVE unit

Условная внутренняя единица behavioural normalization для сопоставления разных никотиновых продуктов. **Не медицинский эквивалент вреда или никотина.**

## Baseline

Исходный уровень употребления конкретного пользователя, относительно которого оценивается динамика.

## Craving

Субъективная тяга/импульс использовать целевой никотиновый продукт.

## Episode

Один наблюдаемый цикл `контекст → craving → need → response → outcome`.

## Trigger / Триггер

Контекст/ситуация, после которой повышается вероятность автоматического никотинового действия.

## Need / Потребность

Функция, которую человек в данный момент пытается получить через привычное действие: пауза, снятие напряжения, удовольствие, переключение и т. п.

## Замена / Replacement

Альтернативное действие, выбранное для удовлетворения той же или близкой функции без целевого никотинового поведения.

## Связка / Link

Повторяющаяся цепочка `ситуация → состояние/потребность → импульс → привычный ответ`, которую пользователь учится замечать и изменять.

## Разорванная Связка / Broken Link

Эпизод, в котором привычный автоматический ответ не последовал или был заметно отложен/заменён по принятому определению версии методологии.

## Смысл / Meaning

Личная причина или направление жизни/идентичности, ради которого человек хочет менять зависимое поведение.

## Successful response

Outcome, который соответствует versioned критериям успешного альтернативного ответа. Не означает «идеальный день» и не равен медицинскому успеху лечения.

## Target dependency

Никотиновый продукт, использование которого человек хочет сократить/прекратить.

## Cessation bridge

Продукт/инструмент, который пользователь временно использует для отказа от другого продукта. Не должен автоматически считаться relapse целевой зависимости.

## NRT

Nicotine Replacement Therapy: никотинзаместительные средства (например spray/gum/patch), используемые как отдельный intervention type.

## Raw event

Исходный факт: количество сигарет, кальянных сессий, vape puffs и т. п. Не зависит от ALIVE equivalence model.

## Derived metric

Пересчитываемая метрика, полученная из raw events и versioned model.

## Together / Вместе

Групповой слой поддержки на разрешённых агрегатах без доступа к private content и без leaderboard.

## UGC

User-generated content: пользовательские Смыслы/Связки/Замены, которые становятся доступными admin review только после явной отправки.

## Methodology version

Версия экспериментальной логики ALIVE, определяющая смысл measurements/criteria.

## Equivalence model

Версия правил преобразования raw nicotine usage в ALIVE units.
