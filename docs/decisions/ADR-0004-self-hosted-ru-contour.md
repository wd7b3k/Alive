# ADR-0004. Собственный сервер в РФ вместо Cloudflare Pages и Supabase Cloud

- Статус: принято
- Дата: 27.08.2026
- Контекст решения: русскоязычный сегмент не открывался у части аудитории из РФ
- Соседнее решение: [`ADR-0003-rebrand.md`](ADR-0003-rebrand.md) — смена имени на
  Habitoff, принятая днём раньше. Решения независимы: ребрендинг отвечал на вопрос
  видимости и бренда, это — на вопрос доступности из РФ. Совпали они по времени
  потому, что оба вытекли из одного аудита 26.08.2026.

## Проблема

Продукт для русскоязычной аудитории жил на Cloudflare Pages с бэкендом в Supabase Cloud
(`eu-west-1`). У заметной части людей в РФ, особенно с мобильных сетей, он не открывался
или открывался непредсказуемо. Ни Cloudflare, ни Supabase не отвечают за доступность
своих адресов из России, и повлиять на это нельзя ничем, кроме ухода.

Второй, менее срочный, но не менее реальный вопрос: персональные данные российских
пользователей — записи о зависимости, срывах, триггерах — лежали в Ирландии.

## Решение

Весь продакшн русскоязычного контура переносится на один собственный VPS в Москве:
статика, база, аутентификация и функции. Cloudflare не участвует ни в одном звене,
включая DNS.

## Рассмотренные альтернативы

**Оставить как есть и надеяться.** Отвергнуто: проблема воспроизводима, а её причина вне
зоны влияния.

**Прокси к Supabase Cloud с российского VPS как промежуточный шаг.** Отвергнуто: плечо
«российский сервер → Cloudflare» проходит через те же ограничения и может резаться так
же, как клиентское. Промежуточная схема добавила бы звено, не сняв риск.

**GitHub как бэкенд** (вопрос владельца 26.08). Отвергнуто по трём независимым причинам,
каждой достаточно. У Pages нет рантайма: ни серверного кода, ни базы, ни сессий, ни RLS —
то есть ровно той границы безопасности, на которой построен продукт; Actions это CI, у
него нет входящего HTTP, и ToS ограничивает его сборкой и публикацией. Лимиты и запреты
Pages прямо исключают использование как хостинга для сервиса и передачу чувствительных
данных. И главное: личные записи в git — худший из возможных вариантов хранения, потому
что история коммитов не забывает, приватный репозиторий даёт доступ «всё или ничего»
вместо изоляции пользователей друг от друга, а данные остались бы в США. Плюс сама
посылка неверна: с 5 мая 2026 доступность GitHub в РФ ощутимо просела.

**Managed PostgreSQL у российских облаков** (Яндекс, VK). Отвергнуто: self-hosted
Supabase работает на своём образе `supabase/postgres` с набором расширений и
суперпользовательскими ролями, которых в каталогах managed-предложений нет. Значит всё
равно нужна обычная виртуалка — а обычную виртуалку Timeweb даёт втрое дешевле.

**Local-first без аккаунтов** (личные записи в IndexedDB, бэкенда нет вовсе). Всерьёз
рассмотрено и отложено, а не отвергнуто. Оно снимает разом хостинг, вход, 152-ФЗ,
бэкапы и мониторинг, и согласуется с заявленной приватностью. Цена: пропадает «Вместе»,
нет синхронизации между устройствами, данные теряются при чистке браузера,
восстановления нет. Для продукта про многомесячный отказ от курения потеря накопленной
истории — тяжёлый удар по доверию. Это продуктовое решение, а не техническое, и принимать
его в момент переезда было бы подменой вопроса.

## Последствия

**Положительные.** Из РФ открывается — проверено с мобильных сетей. Персональные данные
физически в России. Расходы предсказуемы и не зависят от чужих тарифных решений.
Дашборда, через которую можно руками поменять прод, больше не существует.

**Отрицательные, принятые осознанно.**

Одна машина — одна точка отказа. Принято на время проверки гипотезы.

Пропали preview-развёртывания: ветка больше не получает URL сама. Смотреть ветку через
`npm run dev` на сервере и SSH-туннель.

Пропал дашборд, по которому было видно, что база жива. Наблюдаемость надо построить
самому, иначе первым мониторингом будет владелец, открывший сайт с телефона.

Появилась эксплуатация, которой не было: обновления образов, бэкапы, восстановление,
сертификаты, дисковое место. Часть автоматизирована, часть остаётся ручной.

Стоимость выросла с нуля до примерно 2 950 ₽/мес (сервер плюс домен).

## Что это решение не меняет

Репозиторий остаётся единственным источником истины. Схема и контент — только миграциями.
Секреты — не в git. Некоммерческий статус, privacy-модель и продуктовые принципы к
инфраструктуре отношения не имеют и остаются прежними.
