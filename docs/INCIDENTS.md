# Журнал: что ломалось и какое правило из этого выросло

Этот файл — не требование к сессии. Требования живут в `AGENTS.md`, и каждое из них
имеет команду, которая падает. Журнал существует, чтобы правило можно было объяснить и
чтобы класс ошибки не открывали заново.

Порядок один: **класс → случаи с датами → чем закрыт**. Случай без даты не записывается.
Класс, у которого нет закрывающей проверки, помечен ⚠ — это долг, а не норма.

Собран 06.09.2026 из `AGENTS.md` (редакция 433 строки), 53 документов проекта Claude за
20.08–05.09 и `docs/ai_sessions/**`. Разбор, из которого файл вырос, —
`docs/tasks/R-20260906-01-process-pravila-bez-proverok.md`.

## 1. Работа осталась на одной машине

Самый дорогой класс за август: семь случаев за две недели.

- **20.08** — пуш заблокирован git-прокси, результат отдан патчем. Доступ не проверен до работы.
- **26.08** — ребрендинг сделан дважды: сначала без доступа к репозиторию, затем заново в коде.
- **27.08** — за неделю четыре сессии подряд оставили ветки локально по нескольку дней, и
  ни одна не нарушила правила, потому что правила не было. Тогда же появилось «сессия
  заканчивается пушем».
- **28.08** — слой доски работ пролежал бандлом с 01:13; ежедневная задача пересборки
  падала на отсутствующем `scripts/board.mjs`. В той же папке к тому моменту лежало
  двадцать бандлов разной свежести. Сессия, добавившая правило о пуше (`d3559da`), в тот
  же день его и нарушила.
- **30.08** — ветка аудита видимости не запушена: у контура сессии нет учётных данных
  GitHub. Работа была сделана до проверки того, можно ли её отдать.
- **31.08** — 18 мест существуют только на машине владельца: 11 веток с неотправленными
  коммитами, 7 без `origin`. Локальный `main` отстаёт на 14.
- **05.09** — `infra/backups/` создан коммитом `2843802` и отсутствует в `origin/main`,
  поэтому блокер пилота три дня описывался и как закрытый, и как открытый.
- **06.09** — `docs/RUNBOOK_KNOWLEDGE_WEEKLY.md` и `docs/tasks/T-20260906-01-…` не
  существуют ни в одной ветке, ни локальной, ни удалённой: только untracked в рабочей
  копии. Постоянная задача понедельника описана именно этим runbook.

**Закрыто:** `scripts/check-local-drift.mjs` в `scripts/state.sh`.
⚠ **Не закрыто:** untracked `.md` в `docs/` не роняют ничего — `T-20260906-02`.

## 3. Проверка, которая не может провалиться

- **24.08** — anon-тест «нашёл» несуществующую утечку: `set local role` вне транзакции —
  пустая операция, запрос шёл от суперпользователя. Тогда же статический тест ловил
  `awareness_content_contexts` вместо `awareness_content`.
- **27.08** — проверка переполнения возвращала 0 при содержимом 403 px в окне 390:
  `scrollWidth − clientWidth` — ненадёжный признак, переполнение съедается обрезкой у
  предка. Скрипт правок с ложной идемпотентностью: маркер «уже применено» смотрел на
  строку `/**`, которая есть в любом файле; две правки из пяти молча пропустились.
- **30.08** — `build_fingerprint` сравнивал `version.json` сам с собой: упасть мог только
  при отсутствии файла.
- **31.08** — четыре витрины из шести падали при первом вызове: `create or replace
  function` принимает тело целиком и проверяет его только при вызове. Проверка счётчиков
  искала строку, которая есть в бандле всегда, и отвечала «работает» при выключенном
  счётчике. Проверка бэкапов двое суток кричала при исправном восстановлении: искала
  метку с выдуманным именем. Канал оповещения считался рабочим — переменные в нём пустые,
  ни одно сообщение не покидало сервер ни разу, включая сообщения бэкапа.
- **05.09** — девятнадцать статических страниц выложены и проверены `curl`: краулерный
  путь отвечал, для людей страницы были невидимы. `try_files` не совпадал с каталогом.

**Закрыто:** инвариант 5 «Не выполнено — значит не сделано» и `app/src/ops-contract.test.ts`;
строка «Экран — открыт в браузере» в таблице выполненности.

## 10. Бытовая среда съедает заходы

- **26.08** — обе сессии упёрлись в CRLF: git показывал изменёнными 184–188 файлов.
  Закрыто `.gitattributes`. Адрес с `www.` при копировании превратился в markdown-ссылку,
  и Caddy взял сертификат на имя `[www.habitoff.ru](https://…)`.
- **27.08** — PowerShell 5.1 не понимает `&&`; `Get-Content` без `-Encoding UTF8` ломает
  кириллицу двойной перекодировкой — так разъехался `cards.json`, и заметили это глазами
  на проде. Пять холостых выкладок подряд: PR не был смержен, примета — `Already up to date`.
- **31.08** — у сессии в облаке нет права удалять файлы: `git` не смог убрать `.lock`,
  коммит не прошёл. Обход — переименовать `.lock` в `.lock.stale`.

**Закрыто:** раздел «Git» в `AGENTS.md`, `CLAUDE.md` раздел «Грабли этого контура».
