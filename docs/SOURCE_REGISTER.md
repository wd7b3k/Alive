# Source Register ALIVE

Реестр конкретных источников, заимствований и научных оснований.

На foundation-этапе документ создаётся как обязательный источник истины, но не заполняется вымышленными ссылками задним числом. Каждое конкретное заимствование добавляется после проверки первоисточника.

## Формат записи

| ID | Механика/утверждение | Источник | Тип использования | Адаптация ALIVE | Evidence status | Copyright/license note | Product location |
|---|---|---|---|---|---|---|---|

## Правила

- предпочитать первичные/авторитетные источники;
- для медицинских рекомендаций фиксировать дату проверки;
- отделять evidence от product hypothesis;
- при прямом заимствовании формулировки проверять copyright/licensing;
- не добавлять источник только для видимости научности;
- исторические записи не удалять при изменении позиции — помечать superseded.

## Уже известные категории для будущего research pass

- nicotine dependence / smoking cessation;
- NRT;
- cue-triggered behaviour;
- behavioural substitution;
- self-monitoring;
- social support;
- relapse/lapse framing;
- implementation intentions;
- mindfulness/attention;
- motivational/identity approaches;
- health effects of quitting;
- hookah exposure;
- vaping/puff variability.

Конкретные citations должны быть добавлены отдельным research release/task до публичных claims.
