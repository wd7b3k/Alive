# Один воркtree — одна сессия

Правило одно, и оно про то, что уже произошло.

**У каждой сессии свой рабочий каталог git. Он создаётся в начале и убирается в конце.**

```bash
git worktree add ../Alive.worktrees/<имя-задачи> -b <ветка> origin/main
# …работа…
git worktree remove ../Alive.worktrees/<имя-задачи>
```

## Что случилось 31.08.2026

Две сессии работали в `Alive.worktrees/observability` одновременно. Каждая считала
каталог своим и переключала в нём ветки. Последствий было три, и ни одно из них не
выглядело как ошибка:

1. **Правки в `app/src/redesign.css` молча исчезли.** Соседняя сессия переключила ветку,
   рабочее дерево переписалось её содержимым. Тесты остались зелёными: проверка
   инвариантов CSS сверяет список селекторов с разрешёнными, а лишняя запись в
   разрешённых никого не смущает. Обнаружилось это тем, что файла не оказалось в коммите.

2. **Три коммита легли на чужую ветку.** `git checkout -b` был сделан в начале сессии, а
   к моменту `git commit` HEAD уже стоял на `agent/monitoring-truth`. Коммиты ушли туда.

3. **`git push` отрапортовал успех.** Он запушил ветку, которую просили, — и она была
   пуста, потому что работа лежала на другой. `Everything up-to-date` при трёх
   несохранённых коммитах.

Общее у всех трёх: **ни одна из проверок не сработала.** Git не жалуется на два процесса
в одном каталоге, тесты проверяют содержимое, а не то, куда оно попало, а `push` честно
делает ровно то, о чём его просили.

## Почему не «договориться»

Договорённость между сессиями невозможна: они не видят друг друга и не знают, что рядом
кто-то есть. Единственное, что работает, — не делить каталог.

## Как понять, что это уже случилось

```bash
git branch --show-current     # та ли ветка, на которой начинали
git reflog -5                 # чужой `checkout: moving from …` в середине сессии
git log --oneline origin/<своя-ветка>..HEAD
```

Если коммиты легли на чужую ветку: **не переписывать её.** Собрать свою ветку заново от
`origin/main` черри-пиком нужных коммитов, а владельцу сказать, что именно осталось на
чужой ветке и почему.
