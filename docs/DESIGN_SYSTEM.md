# Дизайн-система Habitoff

Источник истины — `app/src/redesign.css`. Этот документ описывает, **как должно быть**;
поймать момент, когда стало иначе, может только `app/src/redesign/css-invariants.test.ts`.
Поэтому каждая шкала здесь имеет соответствующий тест.

Решение о системе — `docs/decisions/ADR-0004-design-system.md`.

## 1. Цвет

### Поверхности

| Токен | Значение | Где |
|---|---|---|
| `--r-bg` | `#061013` | фон приложения |
| `--r-bg2` | `#09171b` | вторая плоскость фона |
| `--r-surface` | `#0d1b1f` | карточка |
| `--r-surface2` | `#112329` | карточка на карточке, поднятый блок |
| `--r-soft` | `#152a2f` | мягкая заливка, поля ввода |

### Текст

| Токен | Значение | Контраст на `--r-bg` / `--r-surface` / `--r-surface2` |
|---|---|---|
| `--r-text` | `#f4f7f5` | 17.84 / 16.31 / 15.02 |
| `--r-muted` | `#a4b6b5` | 9.11 / 8.32 / 7.67 |
| `--r-dim` | `#7d9291` | 5.86 / 5.36 / 4.93 |

`--r-dim` был `#718584` и давал 4.16 на `--r-surface2` — ниже AA для основного текста.
Подтянут до `#7d9291`: теперь все три поверхности проходят AA.

### Роли акцентов — правило, из которого выводится каждое решение

| Токен | Значение | Отвечает за |
|---|---|---|
| `--r-teal` | `#51ddd0` | **действие**: кнопки, ссылки, активная вкладка, ползунки, графики |
| `--r-teal-dim` | `#3aa8a0` | нажатое и выключенное состояние действия |
| `--r-sand` | `#e0c9a6` | **человек и личное**: свои смыслы, свои записи, подставленное «про тебя» |
| `--r-sand-dim` | `#a8977e` | вторичный текст личного слоя |
| `--r-ok` | `#6fcf97` | «хорошо подтверждено», успешный исход |
| `--r-amber` | `#f2ca69` | «правдоподобно», миф, внимание |
| `--r-red` | `#f09a9a` | **только** деструктивные действия владельца: удаление аккаунта, экспорт |

Контраст всех акцентов на всех трёх поверхностях — не ниже 7.5:1, AA проходят все.

**Красный никогда не кодирует поведение человека.** В системе нет и не будет цвета
«ты подвёл»: срыв — это данные, а не оценка (P4).

**«Гипотеза» своего цвета не получает** — она кодируется `--r-dim`. Три уровня
подтверждённости различаются не только цветом, но и подписью.

### Лайм выведен

`--r-lime` и `--r-lime2` удалены. До редизайна лайм означал одновременно четыре вещи —
действие, успех, цель и миф — и им же был покрашен `.r-evidence-badge.level-a`, то есть
уровень доказательности носил фирменный цвет продукта. Полная карта миграции — в ADR-0004.

Проверяется тестом: `css` не должен содержать `--r-lime`.

## 2. Типографика

Шрифт — Inter. Новых веб-шрифтов не добавляется: из России продукт упирается в лимит
около 16 КБ на соединение, и лишний файл шрифта — это отказ загрузки, а не украшение.

| Токен | Кегль | Роль |
|---|---|---|
| `--r-fs-kicker` | 10px | надзаголовок, uppercase, `letter-spacing:.05em` |
| `--r-fs-xs` | 11px | метки, счётчики, сноски |
| `--r-fs-sm` | 13px | вторичный текст, подписи |
| `--r-fs-body` | 15px | основной текст |
| `--r-fs-lead` | 17px | вводный абзац |
| `--r-fs-h3` | 20px | заголовок блока |
| `--r-fs-h2` | 24px | заголовок раздела |
| `--r-fs-h1` | 29px | заголовок экрана |
| `--r-fs-display` | 35px | крупные числа, витрина |
| `--r-fs-hero` | 44px | герой главной |

До редизайна в файле было **32 разных размера**, включая 8 и 8.5 px — нечитаемые на
телефоне. Ничего мельче 10 px в системе больше нет, и 10 px существует только для
uppercase-надзаголовка, где межбуквенное расстояние компенсирует кегль.

Проверяется тестом: значения `font-size` — только из шкалы.

## 3. Отступы

`--r-sp-1…8` = 4, 8, 12, 16, 20, 24, 32, 40 px.

Применяется к `padding`, `gap`, `column-gap`, `row-gap`. Проверяется тестом.

**Исключение, зафиксированное намеренно:** значения внутри `calc()`, `max()`, `min()`,
`env()` из проверки исключены. Там живут safe-area и ширина контейнера (`1160px`),
к шкале отступов они отношения не имеют. Отдельно вне шкалы оставлены `70px` и `80px`
в нижнем отступе экранов — это высота мобильной навигации, а не отступ.

## 4. Радиусы

| Токен | Значение | Где |
|---|---|---|
| `--r-r-sm` | 8px | чипы, бейджи, мелкие поля |
| `--r-r-md` | 12px | кнопки, поля ввода |
| `--r-r-lg` | 16px | карточки |
| `--r-r-xl` | 22px | крупные панели, главная CTA |
| `--r-r-2xl` | 28px | модалки, секции |
| `--r-r-full` | 999px | аватары, круглые кнопки |

До редизайна было **23 разных значения** — соседние карточки скруглялись на 13, 14, 15,
17, 20 и 21 px. Проверяется тестом.

## 5. Глубина

Три уровня, многослойные (ambient + direct):

| Токен | Где |
|---|---|
| плоско | рамка `--r-line`, без тени |
| `--r-elev-1` | карточка: `0 1px 2px rgba(0,0,0,.28), 0 8px 24px -12px rgba(0,0,0,.55)` |
| `--r-elev-2` | модалка: `0 2px 6px rgba(0,0,0,.34), 0 32px 64px -24px rgba(0,0,0,.7)` |

## 6. Движение

| Токен | Значение |
|---|---|
| `--r-ease-out` | `cubic-bezier(.22,1,.36,1)` |
| `--r-ease-in-out` | `cubic-bezier(.65,0,.35,1)` |
| `--r-dur-fast` | 120ms — hover, press |
| `--r-dur-base` | 180ms — смена состояния |
| `--r-dur-slow` | 260ms — вход экрана, модалка |
| `--r-dur-breath` | 5200ms — дыхание главной CTA |

Правила:

- анимируются только `transform` и `opacity` — ничего, что вызывает reflow;
- hover — подъём `translateY(-1px)`, нажатие — `scale(.995)`, а не смена заливки;
- главная CTA дышит с амплитудой `scale(1.008)` и периодом 5.2 с — медленнее спокойного
  дыхания, чтобы не подгонять человека;
- `@media(prefers-reduced-motion:reduce)` отключает **всё** перечисленное:
  `transition:none`, `animation:none`, `transform:none` на состояниях CTA.

**Сознательно не сделано:** count-up чисел, draw-in графиков, skeleton-shimmer.
Им нужен JavaScript на самом тяжёлом экране, а бандл 591 КБ и на первом экране 30
запросов к Supabase с дублями. Этот паттерн переделывает ветка переезда; скелетоны,
построенные под него, пришлось бы выбросить вместе с ним.

## 7. Компоненты и их состояния

У каждого интерактивного компонента шесть состояний:
`default / hover / active / focus-visible / disabled / loading`.

| Компонент | Селектор | Заметки |
|---|---|---|
| Кнопка | `.r-button`, `.r-button.primary`, `.r-button.ghost` | каждый вариант объявлен **ровно один раз** — проверяется тестом |
| Главная CTA | `.r-craving` | не `.r-button`: составная карточка с иконкой, заголовком и пояснением |
| Карточка контекста | `.r-trigger-card` | стилизуется и без класса — проверяется тестом |
| Карточка знания | `.r-knowledge-card`, `.r-awareness-card` | вариант `.myth` — янтарный |
| Карточка смысла | `.r-goal-card` | вариант `.goal` — песочный |
| Эпизод | `.r-episode-card` | `.success` — `--r-ok` |
| Бейдж доказательности | `.r-evidence-badge` | `.level-a` — `--r-ok` |
| Модалка | `.r-modal` | `--r-elev-2` |
| Ползунок | `.r-slider input` | `accent-color: var(--r-teal)` |
| Таб-бар | `.r-mobile-nav`, `.r-desktop-nav` | активная вкладка — `--r-teal` |
| Подставленное значение | `.r-flow-prefill` | песочная рамка и полоса слева, кнопка изменения рядом |

## 8. Доступность — часть системы, а не отдельный чек-лист

- **Фокус виден везде.** `:focus-visible` даёт `outline: 2px solid var(--r-sand)` с
  отступом 3px на всех интерактивных элементах. До редизайна клавиатурная навигация
  местами была невидима.
- **Тач-таргеты** не меньше 44×44, высота основных действий не меньше 48.
- **Отступ от края экрана** не меньше 16px, safe-area учтена через `env()`.
- **Ничто не кодируется только цветом.** Отключённая кнопка меняет и прозрачность, и
  курсор; уровень подтверждённости имеет подпись, а не только оттенок.
- **Контраст** — не ниже AA для основного текста на всех трёх поверхностях; числа в §1.
- **`prefers-reduced-motion`** отключает всё движение, включая дыхание CTA.

## 9. Как добавить экран

1. Взять поверхность из §1, кегль из §2, отступы из §3, радиус из §4.
2. Определить **одно** первичное действие и покрасить его `--r-teal`. Всё личное на
   экране — `--r-sand`. Статусы — `--r-ok` / `--r-amber` / `--r-dim`.
3. Прописать все шесть состояний интерактивных элементов.
4. Написать пустое состояние: оно объясняет и предлагает следующий шаг, а не пугает.
5. Проверить тон: не обещает результат, не осуждает, не командует.
6. Добавить раздел в `docs/SCREENS.md` по шаблону.
7. Прогнать `npm run test` — шкалы проверяются автоматически.
