# Запрос владельца, 28.08.2026

Организовать систему мониторинга habitoff.ru по направлениям:

1. Техническая доступность и быстродействие по всем ключевым элементам системы.
2. Продуктовая аналитика: база новых и постоянных пользователей, отток с сегментацией
   вероятных причин, гео, источники трафика, воронка вовлечения, когортный анализ.

Отдельно — довести до прода счётчики Яндекс Метрики и Вебмастера, Google Analytics и
Search Console.

## Решения владельца, принятые в ходе согласования

- Счётчики ставятся **везде, включая залогиненное приложение**. Инвариант «никаких
  внешних сервисов в рантайме» снимается сознательно, с ADR и правкой согласия.
- **Вебвизор выключен.** Электронная коммерция и контентная аналитика — тоже.
- Продуктовые метрики считаются **своими SQL-витринами**, показываются на `/health`.
- Технический мониторинг — **свой лёгкий стек**, алерты в Telegram (`@HO_tech_bot`),
  бот разворачивается **на втором сервере**.
- Пререндер публичных страниц входит в работу: без него Вебмастер и Search Console пусты.
- Опорных метрик две: недельные участники с зафиксированным результатом и снижение
  расхода против исходного уровня.
- Юридический слой под GA4 владелец закрывает сам, позже.
- Система контекстных пушей появится позже; слой событий закладывается под неё сразу.
- Токен бота хранится только на втором сервере, в `/etc/habitoff-alerts.env`.
- Счётчик Метрики — 111983810, поток GA4 — `G-YB35G45MFW`.
