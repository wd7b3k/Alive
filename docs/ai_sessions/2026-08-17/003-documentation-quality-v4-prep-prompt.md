# Prompt — documentation, research, quality process и подготовка 4.0

Дата: 2026-08-17

## Запрос владельца

1. Актуализировать README проекта.
2. Ввести жёсткое правило: все значимые изменения, решения и roadmap документируются в отдельных файлах так, чтобы разработку мог безболезненно продолжить любой агент.
3. Сразу формировать качественную базу исследований и дизайн-требований на основе сильных конкурентных продуктов, привычных UX-паттернов и современных исследований.
4. Создать регулярный мониторинг новых исследований, открытий, трендов и конкурентов; значимые прорывы предлагать к внедрению.
5. Создать отдельные правила разработки, уменьшающие ошибки и делающие процесс data-first.
6. Подготовить master prompt для Codex на первый release серии 4.0.
7. Дополнительное требование владельца: самостоятельно использовать полезные специализированные skills и рекомендовать их Codex. Качество предыдущей работы Codex неудовлетворительно; нужно изменить сам процесс, если одной документации недостаточно.

## Ограничения

- не начинать runtime 4.0 в этой сессии;
- не применять новые migrations к live DB;
- repo остаётся source of truth;
- не терять историю решений;
- все новые правила должны уменьшать ошибки, а не становиться формальной бюрократией;
- локальный LLM остаётся после Product Evidence Gate.
