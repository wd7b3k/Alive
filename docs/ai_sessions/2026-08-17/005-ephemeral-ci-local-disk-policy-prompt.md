# Prompt — бесплатная DB validation и политика локального диска

Дата: 2026-08-17

Владелец подтвердил новый рабочий принцип:

1. После завершения задачи Codex и его финального отчёта независимая проверка repository/PR/CI выполняется отдельно по запросу владельца.
2. Не использовать платную Supabase development/preview branch на текущей стадии; найти бесплатный воспроизводимый способ migration/RLS/E2E validation.
3. Codex не должен использовать локальный диск владельца как постоянное рабочее хранилище артефактов. Всё долговечное и нужное для продолжения разработки должно жить в repository.
4. Временные build/test/database артефакты по возможности выполнять на ephemeral remote infrastructure.
5. Правило необходимо записать в каноническую документацию и историю решений.
