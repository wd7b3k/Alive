# Запрос владельца — Codex environment preflight

Дата: 2026-08-17

## Контекст

Первый запуск Codex на `4.0.0-alpha.1` начался в sandbox без локального checkout репозитория.

Codex сообщил, что видит только служебные каталоги `work/` и `outputs/`, не находит `.git` и `AGENTS.md`, после чего начал рассматривать GitHub Connector как возможный способ восстановить контекст и продолжить работу.

## Запрос владельца

Исправить процесс и дать новый prompt для Codex.

Ранее согласованное направление:

- обязательный environment preflight;
- fail-fast при отсутствии локального checkout;
- GitHub Connector не должен заменять рабочую копию;
- качество работы Codex должно улучшаться через process gates, skills, tests, browser QA и независимый review, а не только за счёт увеличения prompt.

## Требование к документированию

Изменение должно быть отражено в repository так, чтобы любой следующий агент понимал:

- какой сбой произошёл;
- почему он важен;
- какое правило принято;
- какой launcher использовать для `4.0.0-alpha.1`;
- когда Codex обязан остановиться вместо импровизации.
