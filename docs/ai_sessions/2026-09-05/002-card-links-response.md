# Карточки связаны друг с другом, источники — без `nofollow`

Работа по `HANDOFF.md` от 05.09.2026, вечер. Ветка `seo/card-links`, PR #76 влит,
прод на `86b8e81`.

## 1. `nofollow` снят

Ссылка на источник и есть то единственное, чем этот продукт отличается от пересказов без
ссылок в той же нише. `nofollow` на ней сообщал поисковику «я за это не отвечаю» — при
том что за источник страница как раз ручается. Остался `noopener`.

Правило в общем компоненте зашито не было: оно стояло инлайном в пререндере, в двух
местах — на ссылке к источнику и на ссылке к `doi`. Оба сняты.

```
$ curl -s https://habitoff.ru/knowledge/calms-me | grep cdc.gov
<a href="https://www.cdc.gov/tobacco/campaign/tips/quit-smoking/7-common-withdrawal-symptoms/index.html" rel="noopener">

nofollow на карточках: calms-me 0, one-does-not-count 0, oral-health 0, too-late-to-quit 0
```

Тест смотрит на атрибут `rel`, а не на упоминание слова. Первая версия проверяла файл
целиком и падала на комментарии, который объясняет, почему `nofollow` здесь не стоит, —
запрет на упоминание запретил бы объяснение вместе с ошибкой.

## 2. Карточки ссылаются друг на друга

Была звезда: хаб и 38 листьев, между листьями пусто. Соседи не выдуманы — общие метки
контекста, пусковые моменты, потребности, замены и категория факта уже лежат в базе;
`services/knowledge-related.ts` их только взвешивает. Метка контекста весит больше всего,
продукт почти ничего не значит: сигарету упоминают все, поэтому продукты дают максимум
единицу целиком, а не по единице за штуку.

Снято с живого домена, все 38 страниц:

```
ссылок на соседей: от 3 до 5
односторонних связей: 0
достижимо из любой карточки: 38 из 38
```

Три правила проверяются тестом, а не глазом: связь двусторонняя, степень от 3 до 5, граф
связный. Плюс четвёртое, без которого работа была бы шумной: результат детерминирован —
та же выгрузка даёт тот же граф, иначе каждая сборка переписывала бы 38 страниц и
выглядела бы изменением там, где ничего не менялось.

Граф строится в четыре прохода, и каждый чинит то, чего не мог предыдущий: сильные пары
до целевой степени, добор до минимума (там допускается и нулевой вес — карточка без
общих меток всё равно обязана быть достижимой), сшивание компонент, порядок вывода по
близости. Если сшить нечем — сборка падает с объяснением, а не отдаёт несвязный граф
молча.

## Замечание в сторону — принято и исправлено

Отчёт прошлой сессии считал «31 карточка короче 400 знаков» по полям карточки. Это
измерение не того: в индекс уходит собранная страница, а она добавляет уровень
доказательности, границы, источник и теперь соседей.

Замер переехал из выгрузки в сборку, где страница есть целиком. По страницам тонких нет
ни одной:

```
предрендер: 6 разделов и 38 карточек каталога;
            самая короткая страница — who_medications, 1157 знаков
```

Строка в `docs/tasks/R-20260905-01-…` поправлена: прежнее число зачёркнуто с пометкой,
что оно артефакт способа измерения, а не состояние каталога.
