# Prompt — первый живой QA под реальным логином

Дата: 2026-08-21

## Контекст

Владелец подключил Chrome через расширение Claude for Chrome, выбрал трек релиза
(«PR: №12, следом рефакторинг») и вошёл в ALIVE своим настоящим Google-аккаунтом.
Впервые за все сессии стали доступны экраны за логином — до этого блок D
(`docs/V3_VISUAL_UX_BASELINE.md`, «Screen-level acceptance») был принципиально
недостижим: ни в облачной песочнице, ни через мост к устройству нет и не должно
быть живых credentials.

## Требования

- Довести PR #12 до зелёного CI (джоба `rls-isolation` падала на каждый push).
- Пройти по экранам за логином и найти то, что раньше было невидимо.
- Ничего не сохранять и не удалять в реальном аккаунте владельца — это его личные
  данные, QA не должен оставлять после себя мусорные эпизоды.
- Найденное чинить только там, где это техническая ошибка с однозначно правильным
  ответом; продуктовые решения — фиксировать как находки для владельца, не
  додумывать за него.
- Релиз не объявлять.
