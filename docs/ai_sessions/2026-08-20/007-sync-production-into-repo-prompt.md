# Prompt — синхронизация production → репозиторий

Дата: 2026-08-21

## Контекст

После применения владельцем миграции дедупликации к живой базе встроенная в неё
проверка вернула ещё один дубликат, которого нет в миграциях репозитория. Раскопка
показала, что расхождение системное: прод давно правился напрямую через Supabase
Dashboard, мимо версионированных миграций.

Владелец, увидев масштаб:

> Прод истина, но синхронизируй его с репо

## Требования

- Принять production за источник истины и подтянуть репозиторий к нему —
  не наоборот; ничего в проде не менять.
- Захватить и схему, и содержимое: недостающие колонки, недостающие строки,
  изменённые формулировки, метаданные.
- Ничего не выдумывать: все значения берутся из прода дословно. Никаких
  «дописанных» замен, оценок доказательности или ссылок на источники.
- Доказать, что синхронизация полная, а не на глаз: база, собранная с нуля из
  миграций, должна совпасть с продом по полям.
- Не объявлять релиз.
