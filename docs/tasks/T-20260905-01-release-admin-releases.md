## Зачем

Ответ на вопрос «что уже внедрено» сейчас собирается вручную из записей сессий, карточек
доски и памяти, и эти три источника расходятся между собой: про бэкапы за четыре дня
репозиторий содержит три несовместимых утверждения. Нужен один экран, отвечающий на этот
вопрос по факту git, а не по пересказу.

Читатель — владелец. Задача экрана — проверяемость и полнота, а не человеческая
формулировка: этим занят публичный `/releases`, и он остаётся нетронутым.

## Предпосылки — проверить первыми командами

- `bash scripts/state.sh` — ветка чистая, доска без ошибок;
- `app/src/redesign/admin.tsx` содержит `ADMIN_SECTIONS` и пункт `releases`;
- `/admin` и `/admin/*` уже перечислены в матчере `@app` в `infra/caddy/Caddyfile`;
- `/admin` входит в `PRIVATE_PAGES` в `app/src/services/seo.ts`;
- `bash scripts/next-adr.sh` — следующий свободный номер ADR.

Расхождения с текстом постановки, найденные проверкой, перечислены в разделе «Результат».

## Инварианты — нарушать нельзя

- **Раздел не публичный**: нет в `PRERENDER_PATHS`, нет в `sitemap.xml`, `noindex`,
  доступ по роли — тем же механизмом, что у `/admin/analytics`. Источник: `docs/ADMIN.md`,
  раздел «Контракт блока»; `AGENTS.md`, Privacy-by-design.
- **Публичный `/releases` не меняется ни одной строкой** — ни `releases.ts`, ни
  `releases.test.ts`. Источник: решение 27.08.2026 о формате страницы, зафиксированное в
  шапке `app/src/redesign/releases.ts`.
- **Никаких обращений к GitHub API из браузера.** Источник: `AGENTS.md`, «никаких внешних
  сервисов в рантайме прода, кроме перечисленных явно».
- **Эвристика называется эвристикой.** Тип изменения, выведенный из путей и глагола
  заголовка, помечается на экране как догадка. Источник: `AGENTS.md`, Evidence-first.
- **Непосчитанное возвращает причину, а не ноль.** Нет git при сборке — раздел показывает
  причину. Источник: `AGENTS.md`, Evidence-first; `docs/ADMIN.md`, «Пустой раздел
  объясняет себя».
- **Исключение из правила `admin_*`**: данных нет в базе, источник — репозиторий.
  Записывается явно в шапке раздела и в ADR, а не нарушается молча. Источник:
  `docs/ADMIN.md`, «Контракт блока».
- **`app/src/generated/` в git не попадает.** Источник: `AGENTS.md`, REPO как source of
  truth — производное не коммитится, а воспроизводится.
- **Основной чанк не растёт.** Источник: `docs/ADMIN.md`, раздел «Вес».

## Что сделать

1. `scripts/changelog-parse.mjs` — чистый разбор вывода `git log`, без ввода-вывода и без
   внешних зависимостей.
2. `scripts/build-changelog.mjs` — один вызов `git log`, версии по коммитам, менявшим
   `app/package.json`, карточки из `docs/board/cards.json`, задачи из `docs/tasks/`.
   Пишет `app/src/generated/changelog.json`. Git недоступен — файл с полем `unavailable`
   и причиной, сборка не падает.
3. `app/src/redesign/admin-releases.tsx` — раздел: группировка по версиям, фильтры в
   адресе строки запроса, раскрытие строки, сверка отпечатка с `/version.json`.
4. Строка `releases` в `ADMIN_SECTIONS`: заголовок «Что сделано», `status: 'live'`,
   `render`.
5. Стили `r-releases-*` в `app/src/redesign.css`.
6. Генерация до сборки, типов, тестов и dev-сервера; `app/src/generated/` в `.gitignore`
   и в `.prettierignore`; в CI полная история, иначе разбирать нечего.
7. ADR со следующим свободным номером: источник — git на сборке, исключение из `admin_*`,
   принятый риск.
8. `docs/ADMIN.md`, `docs/NAVIGATOR.md`, `docs/CURRENT_STATE.md` — тем же PR.

## Приёмка — команды и ожидаемый вывод

- `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test`, `npm run build`
  в `app/` — зелено, существующие тесты не переписаны.
- Новые тесты: разбор `git log` на фикстуре (трейлер `Board:`, номер PR, тема по путям,
  интервалы версий, коммит без всего этого); отсутствие git даёт файл с причиной;
  `/admin/releases` отсутствует в `PRERENDER_PATHS` и в `sitemap.xml`; `caddy-routes.test.ts`
  проходит.
- `node scripts/build-changelog.mjs` на реальной истории: число записей равно
  `git rev-list --count HEAD`, ни один коммит не потерян и не задвоен.
- Скриншоты раздела на 390 и 1280, свёрнутое и раскрытое изменение.

## Не делать

- Не трогать публичный `/releases`.
- Не заводить свой маршрут, своё меню и свою проверку роли.
- Не ходить в GitHub API из браузера.
- Не переносить список релизов в базу: альтернатива описана в ADR и в эту задачу не входит.
