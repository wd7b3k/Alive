## Инварианты

- Неизвестный путь отдаёт 404, а не подставленную главную; список адресов в `Caddyfile`
  сверяется тестом с кодом (`services/caddy-routes.test.ts`)
- У каждого адреса свой `title`, `description`, `canonical` и своё тело в предрендере;
  второй копии заголовка не существует — источник `services/seo.ts` (`services/prerender.ts`)
- Английская страница не объявляет `canonical` на русскую и наоборот: это разные страницы,
  связанные `hreflang`, а не копии
- Личные экраны остаются `noindex` в обеих локалях (`services/seo.ts`, `robots.test.ts`)
- Смена языка не теряет экран: с `/knowledge` переключатель ведёт на `/en/facts`,
  а не на `/en/`

## Что сделать

1. Роутер: префикс `/en` для всех публичных и личных экранов, слаги — английские, по
   `docs/GLOSSARY_EN.md`. Таблица соответствия `ru-путь ↔ en-путь` в одном месте,
   тест на полноту в обе стороны.
2. `services/seo.ts`: `PAGES` становится двумерным (путь × локаль); `PRERENDER_PATHS`
   и `NOINDEX_PATHS` выводятся из него, как сейчас, — руками второй список не пишется.
3. `services/prerender.ts`: два дерева, английская навигация, английские тела страниц,
   `<html lang>`, `og:locale`/`og:locale:alternate`, `hreflang` на пару и `x-default`
   на русскую версию, JSON-LD с `inLanguage`.
4. `sitemap.xml` — оба дерева; `robots.txt` — запреты для обеих локалей.
5. `infra/caddy/Caddyfile`: `/en/*` в матчер `@app`, предрендеренные английские адреса
   отдаются файлами; `caddy-routes.test.ts` расширяется на английские пути.
6. Переключатель языка: в шапке публичных экранов и в профиле, ставит cookie
   `habitoff_locale` (год, `SameSite=Lax`), переводит на парный адрес текущего экрана.
7. `scripts/render-og-card.mjs` — английская карточка `og-card-en.png`;
   `site.webmanifest` — имя и описание на локаль.
8. Документы: `docs/SEO_AND_ANALYTICS.md`, `docs/ARCHITECTURE.md`, `docs/SCREENS.md`,
   `docs/CURRENT_STATE.md`, навигатор.

## Приёмка

- `cd app && npm test && npm run build` — зелено
- `ls app/dist/en` — по файлу `index.html` на каждый английский публичный адрес
- `grep -c hreflang app/dist/index.html app/dist/en/index.html` — по паре на страницу
- `grep -o '<link rel="canonical"[^>]*>' app/dist/en/facts/index.html` — canonical на
