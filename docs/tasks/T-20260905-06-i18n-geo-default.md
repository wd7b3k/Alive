## Доступы

    положить в `habitoff-caddy.env`, в репозиторий не коммитить

## Инварианты

- Адрес сильнее автоопределения: `/en/…` открывается по-английски из любой страны,
  `/…` — по-русски (разбор §3). Иначе присланная ссылка ломается у получателя
- Выбор человека сильнее всего: cookie `habitoff_locale` не переопределяется гео
- Роботы не редиректятся: краулер ходит из США и склеил бы локали. Ответ отдаётся
  с `Vary: Cookie`, связь версий — на `hreflang` (`docs/SEO_AND_ANALYTICS.md`)
- В счётчики и события не уходит IP и ничего нового о человеке: добавляется только код
  локали (`docs/PRIVACY_AND_DATA.md`)
- Стек поднимается сам после `reboot`; неизвестный путь по-прежнему 404

## Что сделать

1. Образ Caddy пересобрать через `xcaddy` с `caddy-maxmind-geolocation`, версию
   зафиксировать, сборку описать в `infra/caddy/README.md`.
2. База GeoLite2-Country на сервере, обновление таймером по образцу
   `infra/backups/units/`, `OnFailure` как у остальных.
3. Проверка свежести базы в `infra/monitoring/checks/` — устаревшая база молча
   превращает гео в «всем русский».
4. Правило в `Caddyfile`: на `/` без cookie и не для роботов — 302 на `/en/`, если
   страна не входит в `RU BY KZ KG AM MD TJ UZ`; при недоступности гео — `Accept-Language`;
   при молчании обоих — русский.
5. Предложение сменить язык на первом экране: одна строка, закрывается навсегда, ставит
   cookie. Работает и там, где редиректа не было.
6. `services/visitor.ts`: локаль в атрибуцию визита; витрина воронки в админке
   разделяет русский и английский трафик.
7. Документы: `docs/INFRASTRUCTURE_STATE.md`, `docs/SEO_AND_ANALYTICS.md`,
   `docs/PRIVACY_AND_DATA.md`, `docs/RUNBOOK_ALERTS.md`, навигатор.

## Приёмка

- `curl -sI https://habitoff.ru/` из РФ → 200, тело русское
- `curl -sI https://habitoff.ru/` с зарубежного адреса (VPS/прокси) → 302 на `/en/`
- Тот же зарубежный запрос с `User-Agent: Googlebot` → 200 и русская главная, без 302
- Запрос с `Cookie: habitoff_locale=ru` из-за рубежа → 200, русская версия
- `curl -sI https://habitoff.ru/en/` из РФ → 200, редиректа нет
- `systemctl reboot`, затем полный прогон `heartbeat.sh` — всё поднялось само
- В заголовках ответа `/` присутствует `Vary: Cookie`

## Не делать

- Не редиректить внутренние адреса и личные экраны.
- Не хранить IP и не передавать страну в счётчики.
- Не вводить третий язык «заодно».
