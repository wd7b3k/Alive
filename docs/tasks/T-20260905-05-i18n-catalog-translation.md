## Инварианты

- Числа, уровни доказательности A/B/C, границы применимости и источники не меняются
  при переводе ни на слово (`docs/TONE_OF_VOICE.md` §9, `docs/METHODOLOGY.md`)
- Перевод носительского уровня, не буквальный; медицинские формулировки не усиливаются
  и не смягчаются
- Ни одной строки без ревью-прохода: черновик не публикуется
- Переводы попадают в базу только миграциями, партиями по каталогам
- `status='published'` ставится лишь тем строкам, чей `source_hash` совпал с текущим
  русским текстом

## Что сделать

1. Порядок партий — по тому, что человек видит раньше: связки и потребности → замены →
   факты и мифы → цели и смыслы → поддержки, награды, сценарии идентичности.
2. На каждую партию: миграция с переводом, ревью-проход отдельной сессией («читай как
   носитель, без русского рядом»), правки, публикация статуса. Один коммит на партию.
3. Границы (`evidence_scope`) и механизмы переводятся особенно осторожно: до 27.08.2026
   там уже жил английский текст, вычищенный как случайный, — теперь он появляется
   осознанно и только в EN-строках.
4. Термины строго по `docs/GLOSSARY_EN.md`; расхождение — правка глоссария отдельным
   коммитом, а не разнобой в карточках.
5. Проверка на неполноту: карточка, у которой переведена часть полей, не публикуется.
