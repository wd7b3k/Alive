## Что сделать

1. Снять с прода сырой HTML каждого публичного адреса обеих локалей: свой `title`,
   свой `h1`, свой canonical, пара `hreflang`, `x-default`, длина тела больше слепка главной.
2. Вёрстка на 320 / 390 / 768: английские строки длиннее в кнопках и вкладках. Прогон
   `css-invariants` на английской локали плюс снимки каждого публичного и личного экрана.
3. Полный проход сценария тяги на английском: триггер → потребность → три замены →
   результат. Числа, склонения, даты, валюта.
4. `sitemap.xml` — оба дерева, `lastmod` живой; отправка карты в обе панели, английские
   адреса добавлены.
5. Замер аналитики: событие с английской локали доезжает, коды событий те же, что
   с русской.
6. `docs/CURRENT_STATE.md` — раздел о двух локалях; `docs/PRODUCTION_READINESS.md` —
   строки английского контура; навигатор.
